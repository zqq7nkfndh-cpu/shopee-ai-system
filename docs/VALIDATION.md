## 機能の確認内容

- 手計算による利益照合。手数料の課金基準、手数料税、購入者送料、値引き、送金、広告、返品引当、原価・送料、ゼロ費用を確認。
- 全6市場で損益分岐価格の切り上げ境界を確認。成立しない料率で偽の推奨価格を返さず、未入力を0として利益を作らないことを確認。
- 同時更新の一方を409で止めること、再読込・プロセス再起動で商品が残ること、SKU重複防止、履歴保存。
- 人間による承認 → 準備完了 → 国別CSVの経路。費用や国別設定を変更すると再承認が必要になること。
- CSVの不正行を事前検証し、重複はスキップ。旧CSVの移行を繰り返しても編集済み商品を上書きしないこと。
- JSONバックアップの秘密情報除外、空環境への復元、不正バックアップの原子的拒否、完全DBのオンラインバックアップと保存権限。
- 認証・CSRF・異なるOriginの拒否・ログイン試行制限・保護ヘッダー・入力型・URLスキーム・数式注入対策。
- OpenAIリクエストはモックで成功・タイムアウト・不正応答を確認。送信項目に仕入れ先URL・原価を含めず、生成しても既存コピーが変わらないこと。
- 全画面と詳細タブの描画、HTMLエスケープ、検索・国フィルター、0と未入力の区別、比較上限、未保存移動、認証期限切れ時の編集内容保持。

画面テストはNodeのVMを用いた描画・操作ロジックの検証です。実ブラウザの代わりにはなりません。
