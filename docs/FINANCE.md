# 利益計算の定義

1商品を1注文で販売する場合の概算です。入力した条件による計算であり、Shopeeの精算処理を再現する認証済みエンジンではありません。複数商品の同梱、注文単位の費用配賦は利用者が1個あたりに直してください。

`P` を現地売価、`d` を値引き率、`B` を購入者負担送料、`X` を1現地通貨あたりのJPYとします。

- 値引き後商品代金 `I = P × (1 − d)`
- 現地通貨売上 `R = I + B`
- 販売／決済／サービス手数料の基準は、それぞれ `I` または `R` を設定
- 手数料 `F = (各基準 × 各料率の合計 + 固定手数料) × (1 + 手数料税率)`
- 送金・換金費 `W = max(0, R − F) × 送金料率`
- 広告費 `A = I × 広告料率`
- 返品・損失引当 `Q = I × 引当率`
- JPY固定費 `C = 原価 + 国内送料 + 国際送料 + 梱包 + 販売者負担関税税等 + その他 − 送料リベート`
- 利益 `Π = (R − F − W − A − Q) × X − C`
- 売上利益率 `Π / (R × X)`

手数料への税を含んだ料率を入力する場合、手数料税率は0にし、二重計上を避けてください。入力時点で控除・相殺済みの送料はリベートを重ねて引かないでください。送金費を実効為替に織り込んだ場合も二重計上に注意します。

損益分岐価格と目標価格は上記関数に対する二分法で算出し、通貨刻みで上方向に丸めます。アプリの刻みはSGD / MYR / PHP / THB = 0.01、TWD / VND = 1です。これは保守的な入力ルールであり、Shopeeの最新価格入力仕様を検証した値ではありません。10億現地通貨以内で達成できなければ「算出不能／達成不能」と表示します。無理に原価の2倍などへ置き換えません。

ストレス試算は、円換算レート下落、国際送料上昇、売価下落を**同時**に反映します。購入者送料、原価、リベート、料率は固定です。税率・料率も変わるケースは設定を変えて別途試算してください。これは赤字確率や最大損失の統計予測ではありません。

段階手数料、上下限、国別免除、新規セラー特典、特別プログラム、源泉税、GST/VATの徴収主体や課税標準、所得税・法人税は自動判定しません。自分の契約・カテゴリに合う実効率と、販売者が負担する税額を入力し、実際の注文明細と照合してください。

計算に使う数値はDecimalで扱い、最後にJPY小数2桁へ四捨五入します。画面の主要指標はJPY整数表示なので、境界近くでは内訳の表示合計とわずかに異なります。
