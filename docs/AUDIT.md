## 問題と対応

| 問題 | 根拠・影響 | 実装した対応 |
|---|---|---|
| 需要を測っていない「自動リサーチ」 | 固定カタログの主観値。実市場の取得経路なし | 着想カタログとして保持。観測情報はURL・日付・条件と保存。未知は空欄 |
| スコアがほぼ満点 | `(od*2 + ju*2 + se + (6-rr) + pp)/9*100` を100でクリップ。5段階値との分母が合わない | 合成スコアを廃止。観測・計算を横並び比較 |
| 「利益30%」が目標の自己実現 | 目標率から逆算した値付けを需要・競合の裏付けなしに推奨 | 入力した現地売価で採算判断。目標価格は別指標として明示 |
| 表示価格と利益の不一致 | `calculate_finance` は推奨価格とその手数料を返しつつ、利益だけexpected_price基準になる | 一つの現地売価から一貫して売上・費用・利益を計算 |
| 全市場一律12%・USD中心 | 手数料定数、JPY/USD固定値、別画面に独立した計算が重複 | 国別・基準別設定、現地通貨・実効為替、Decimalの単一計算関数 |
| 費用の欠落・NaN | 梱包や関税等が経路で異なる。CSVの空欄やNaNを0扱い | 未入力は未算出。ゼロも明示。有限値・範囲・型をAPIで検証 |
| コピーに根拠のない断定 | Authentic、Made in Japan、Fast Ship、追跡・納期・人気・保証を自動挿入。日本語名が残る | 確認済み仕様だけを使う英語定型案、任意のAI自然翻訳、手動レビュー |
| 編集した本文が保存されない | Streamlitのtext_area入力値をCSV更新へ渡していない | 専用保存API・確認メッセージ・未保存の移動警告 |
| 再生成で承認・編集を消失 | `run()`が全件approved=FalseでCSVをopen("w") | 再生成は提案のみ。既存レコードに対する明示的保存以外で上書きしない |
| 商品ID不足・重複 | 商品名/国、日付/国/商品名など経路ごとにキーが違う | UUID・国別SKU/正規化名の一意制約、重複は409または取り込みスキップ |
| 他国の承認状態に混入 | `_sync_dashboard_csv`は商品名だけで一致させる | SQLiteのID単位更新。別国は別レコード |
| 複数CSV/JSONの競合・非原子的保存 | 排他制御やトランザクションがなく、読み書き間で競合 | WAL・BEGIN IMMEDIATE・更新version確認・変更履歴 |
| 仕入れトラッカーと下書きの分離 | 再計算・保存しても承認判定や出力と連動しない | 同じ商品データ・同じ利益関数へ統合 |
| 強制承認と出力の不整合 | 高リスクを承認できるが出力では除外 | 高リスクは承認を止める。準備完了後も全件再検証 |
| 「公式Mass Upload」と断定 | 独自ヘッダー、出典不明の2024共通仕様、Supplier URL等を含む。実テンプレート確認なし | 転記用CSVへ訂正。文字数・属性・物流・言語の確認メモを国別管理 |
| 必須本文や形式を未検証 | タイトル/本文空欄を確認せず、勝手に切詰める。URL・カテゴリは単に非空 | 空欄、正の数、URL形式、カテゴリ数値、設定文字数上限、言語等を検証。切詰めない |
| 国切替で別商品のフォーム値混入 | Streamlit追加入力のwidget keyは国を含まないidx | UUID単位の商品詳細と明示的状態管理 |
| 破損JSONを黙って空にする | `except Exception: pass` | 読み込みエラーを明示。復元は全件検証して一括処理 |
| 認証・監査・保護不足 | アプリ独自認証なし。NodeプロキシはCSP等を剥がしCORS全許可 | パスワード・opaque session・CSRF・同一オリジン・CSP・サイズ制限・試行制限 |
| CSV数式注入 | 入力文字列をそのままCSV出力 | 危険な先頭文字にアポストロフィ |
| 実行・依存・配置の混在 | root main.pyはHello、Replitは存在しないai_side_biz/main.pyを起動。空のPostgres依存も残る | Pythonの単一アプリ、実行CLI、依存固定、Docker/Gunicorn/CI |
| テスト不足 | 運用機能のテスト・CIがない | 数値の手計算照合、状態・保存・移行・復元・認証・競合・起動・画面ロジックを検証 |

## 構成の選択

Flask + SQLite + ES modules/CSSの単一アプリへ整理しました。小規模な個人利用で、NodeとPythonを二重運用せず、APIキーや外部DBなしで開始できるためです。業務処理、保存、API、生成、移行、出力をモジュールで分離しています。SQLiteは単一ホスト前提です。

旧版の47件の着想カタログ・入力/下書きサンプル・手動承認と出品準備の考え方は残しました。未使用のNodeひな形、Streamlit本体、DRY_RUN切替で将来の自動出品を誘導するUI・APIプレースホルダーを除去しました。過去コードはGit履歴に残ります。

## 継続する制限

実ショップの精算・最新テンプレート・公式商品/物流APIと実地照合していません。画像はURL保存のみ、国別の全属性の自動マッピングや公式XLSXの生成はありません。ライブ需要・競合・為替・在庫取得もありません。ユーザーが集めた情報を正しく管理・比較し、最終確認を支援する構成です。詳しくは [OFFICIAL_SOURCES.md](OFFICIAL_SOURCES.md)。
